Panduan & koneksi

Versi web ini menggunakan database Firebase yang sama dengan proyek Android lampiran: data-surat-f013c.

  1. Unggah index.html ke repositori GitHub Anda.
  2. Buka Settings → Pages → Deploy from a branch → main → / (root) → Save.
  3. Buka alamat GitHub Pages setelah proses publikasi selesai. Koneksi internet diperlukan untuk memuat Firebase dan data.

Data yang dipakai: surat_keluar_ibs dan surat_masuk_ibs. Kolom dan tipe data mengikuti Android; tanggal disimpan sebagai dd-MM-yyyy dan waktu input sebagai angka milidetik. Edit mempertahankan waktu input asli.

Jika koneksi ditolak: konfigurasi awal diambil dari proyek Android. Bila API key dibatasi khusus Android, daftarkan aplikasi Web pada proyek Firebase yang sama, lalu masukkan JSON firebaseConfig Web di bawah. Rules Firestore dan App Check yang berlaku juga harus mengizinkan klien web. Jangan mengubah Rules menjadi akses publik untuk mengatasi kesalahan. Aplikasi Android sumber tidak memuat login; halaman ini juga mengikuti alur tersebut. Jika Rules memerlukan login, perlu penambahan autentikasi yang sesuai.

Keamanan: kode GitHub Pages dapat dilihat pengunjung. Konfigurasi Firebase bukan kata sandi; pembatasan akses data harus ditegakkan melalui Firebase Rules. Jangan memasukkan service account, private key, atau token GitHub.

Nomor berikutnya disarankan dari nomor terbesar yang tersedia, keluar dengan minimal tiga digit. Nomor tetap dapat diedit. Penomoran bersama Android belum memakai penghitung transaksional; cek nomor bila beberapa pengguna menginput bersamaan.

CSV mencakup seluruh hasil pencarian, bukan hanya halaman aktif. Ekspor menetralkan awalan formula spreadsheet. Saran alamat tersimpan di browser ini dan dilengkapi dari data aktif.
